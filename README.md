# albertzorzolan.github.io

Source for Albert Zorzolan's personal site, served by GitHub Pages at https://albertzorzolan.github.io. It is plain HTML and CSS with no build step: edit `index.html` (content) or `styles.css` (look), commit, and push to `main`.

When you change `styles.css` or `vault.js`, also change the `?v=` value where `index.html` loads them, so visitors with an old cached copy get the new file.
