# albertzorzolan.github.io

Source for Albert Zorzolan's personal site, served by GitHub Pages at https://albertzorzolan.github.io. It is plain HTML and CSS with no build step. Each section has its own page: `index.html` (home), `projects.html`, `experience.html`, `creative.html` and `about.html`. They share `styles.css` for the look. Edit a page, commit, and push to `main`.

The header nav and footer are repeated on every page, so change all five when you edit them.

When you change `styles.css`, also change the `?v=` value where each page loads it (the same value on all five), so visitors with an old cached copy get the new file.
